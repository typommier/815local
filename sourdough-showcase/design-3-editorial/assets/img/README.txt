DROP YOUR IMAGE FILES IN THIS FOLDER
=====================================

This design (Modern Editorial) pulls these images automatically. Just match the
filenames. Until a file is here, that spot shows a neat placeholder, so nothing
looks broken.

FLYERS (Markets page gallery):
  flyer-vendors.jpg    -> the June 7 vendor-lineup flyer
  flyer-schedule.jpg   -> the every-other-Sunday season schedule flyer

PHOTOS:
  hero.jpg     -> big homepage hero image (a great crust/crumb or cart shot)
  story.jpg    -> "our story" image (you, the kitchen, hands in dough)
  market.jpg   -> a market-day photo (your booth at the market)
  cart.jpg     -> a photo of the self-serve cart

NOTES:
- JPG or PNG both work. Keep the names exactly as above (lowercase).
- Landscape works best for hero.jpg; portrait/upright works best for story.jpg,
  market.jpg, cart.jpg, and the flyers.
- If you use a different filename, update the matching src="" in the HTML.
