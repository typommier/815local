Import Photos

Two importers, same destination. Both mirror what they find into Supabase storage so the listing renders fast and we are not dependent on the original host.
From a Website
Scrapes the homepage for <img>, og:image, and twitter:image URLs, filters out icons and theme assets, then mirrors the survivors. Takes 20-40 seconds.
From Google Places
Calls the Places API for a known Place ID, pulls up to 5 photos, then mirrors them. Takes 10-20 seconds. Skips businesses that already have photos unless you check Overwrite.
